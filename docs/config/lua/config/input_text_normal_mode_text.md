# `input_text_normal_mode_text = "NORMAL"`

{{since('nightly')}}

Specifies the text displayed in the mode indicator when the
[InputText](../keyassignment/InputText.md) editor is in Normal mode.

The default value is `"NORMAL"`.

```lua
config.input_text_normal_mode_text = 'NOR'
```
