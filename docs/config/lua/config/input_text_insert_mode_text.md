# `input_text_insert_mode_text = "INSERT"`

{{since('nightly')}}

Specifies the text displayed in the mode indicator when the
[InputText](../keyassignment/InputText.md) editor is in Insert mode.

The default value is `"INSERT"`.

```lua
config.input_text_insert_mode_text = 'INS'
```
