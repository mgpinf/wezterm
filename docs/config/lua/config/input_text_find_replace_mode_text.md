# `input_text_find_replace_mode_text = "S/R"`

{{since('nightly')}}

Specifies the text displayed in the mode indicator when the
[InputText](../keyassignment/InputText.md) editor is in Find/Replace mode.

The default value is `"S/R"`.

```lua
config.input_text_find_replace_mode_text = 'FIND/REPLACE'
```
