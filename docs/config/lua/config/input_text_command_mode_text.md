# `input_text_command_mode_text = "COMMAND"`

{{since('nightly')}}

Specifies the text displayed in the mode indicator when the
[InputText](../keyassignment/InputText.md) editor is in Command/Search mode.

The default value is `"COMMAND"`.

```lua
config.input_text_command_mode_text = 'CMD'
```
