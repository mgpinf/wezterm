# `input_text_visual_line_mode_text = "VISUAL LINE"`

{{since('nightly')}}

Specifies the text displayed in the mode indicator when the
[InputText](../keyassignment/InputText.md) editor is in Visual Line mode.

The default value is `"VISUAL LINE"`.

```lua
config.input_text_visual_line_mode_text = 'V-LINE'
```
