# `input_text_visual_block_mode_text = "VISUAL BLOCK"`

{{since('nightly')}}

Specifies the text displayed in the mode indicator when the
[InputText](../keyassignment/InputText.md) editor is in Visual Block mode.

The default value is `"VISUAL BLOCK"`.

```lua
config.input_text_visual_block_mode_text = 'V-BLOCK'
```
