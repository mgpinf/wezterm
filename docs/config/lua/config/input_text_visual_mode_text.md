# `input_text_visual_mode_text = "VISUAL"`

{{since('nightly')}}

Specifies the text displayed in the mode indicator when the
[InputText](../keyassignment/InputText.md) editor is in Visual mode.

The default value is `"VISUAL"`.

```lua
config.input_text_visual_mode_text = 'VIS'
```
