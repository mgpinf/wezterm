# `input_text_replace_mode_text = "REPLACE"`

{{since('nightly')}}

Specifies the text displayed in the mode indicator when the
[InputText](../keyassignment/InputText.md) editor is in Replace mode.

The default value is `"REPLACE"`.

```lua
config.input_text_replace_mode_text = 'REP'
```
