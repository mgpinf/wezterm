# `wezterm.crypto.sha256(data)`

{{since('nightly')}}

Computes the SHA-256 hash of the input data and returns it as a lowercase
hexadecimal string.

```lua
local wezterm = require 'wezterm'

local hash = wezterm.crypto.sha256 'hello'
-- Returns: "2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824"
```
