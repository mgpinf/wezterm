# `wezterm.crypto.sha512(data)`

{{since('nightly')}}

Computes the SHA-512 hash of the input data and returns it as a lowercase
hexadecimal string.

```lua
local wezterm = require 'wezterm'

local hash = wezterm.crypto.sha512 'hello'
-- Returns: "9b71d224bd62f3785d96d46ad3ea3d73319bfbc2890caadae2dff72519673ca7..."
```
