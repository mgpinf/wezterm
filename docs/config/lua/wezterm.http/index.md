# `wezterm.http`

The `wezterm.http` module provides functions for making HTTP requests from Lua.

## Functions

- [get](get.md) - Perform an HTTP GET request
- [post](post.md) - Perform an HTTP POST request
- [request](request.md) - Perform a custom HTTP request
